## 当前维护原则（用户 2026-10-28 授权）

- **当前文件始终保持有效**：新证据、新决定或任务结果经确认后，应在同次工作结束前更新相关入口；不把过时内容长期堆在文件开头。
- **可以直接覆盖或删除已被取代、明显不适用的文件**。先检查准确目标、关联引用和是否仍具独立证据价值；删除/覆盖要在提交说明中列明原因。存疑时标待核，不能凭日期新旧就删除有效证据。
- Git 提交历史用于误删恢复和审计，但**旧版本不再作为当前入口持续展示**。不要对已经推送的提交强制改写历史。
- **没有自动后台实时同步**：所谓实时，是指每次获作者确认的重要变化在本次任务中及时更新 GitHub，下一窗口先读取最新提交。
- `main` 是当前有效状态；候选稿和未经确认的推断不能伪装成已采纳内容。可以用分支/PR 审核风险较高的改动。
- **保密边界不变**：除作者明确允许的精选 Markdown，不推送原始 Word、Excel、PPT、图片、录音/完整转写、第三方论文 PDF、密钥、私人材料和未经审查的整份聊天记录。
