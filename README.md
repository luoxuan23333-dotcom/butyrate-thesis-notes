## 当前实验主线（来自2026-11-05候选Word，不是原始数据认证）

- But-0→But-6：组合基因敲除与整合，丁酸浓度现稿10.53→22.07 g/L。
- ARTP→UV→ARTP：每轮**100株候选突变株，另加1株当轮亲本对照**；对应16、26、24株正向候选，摇瓶代表株But-6A100 / But-6B100 / But-6C100 为27.73 / 31.93 / 34.93 g/L。
- 酵母粉、蛋白胨、玉米浆、糖蜜单因素递进比较；现稿优化摇瓶40.47 g/L。
- 5 L补料分批发酵：0–24 h batch、24–48 h feeding；现稿48 h达58.63 g/L，全程平均生产强度1.22 g/(L·h)；0.59 g/g得率待原始糖耗与补料核对。
