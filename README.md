# 丁酸毕业论文：共同知识库

此仓库用于 **ChatGPT ↔ Codex** 同步已经确认的论文背景、导师要求、写作规范、文献分析与工作进度。仅供协作使用，并非论文主稿。

## 当前约定
1. **原始证据优先**：本地最新《毕业设计.docx》、原始 Excel、图表及正式文献是事实依据。Markdown 仅作索引、规则和决议记录，不能替代原件。
2. **确认后才更新**：讨论中的设想不直接改成有效要求；用户确认的规则、章节版本或任务进度才提交更新。旧决定保留历史，但必须标明失效。
3. **按需读取**：先看最新有效状态，再定位对应证据；不要每次从头阅读所有历史及全部文献。
4. **一次集中验收**：优先校验数据、对照、逻辑、研究范围和导师要求；仅因语言仍可更优而反复改写并非必要。
5. **严守证据边界**：不得补造培养参数、检测方法、统计显著性、遗传稳定性或分子机制。
6. **同步步骤**：Codex 开始处理前先拉取远端最新提交；处理完成后仅提交相关、已核对的知识库更新并推送。ChatGPT 修改仓库前读取最新版本，遇到冲突时先比较再合并。
7. **保密范围**：仅同步明确获准的 Markdown；不得将论文 Word、原始 Excel、实验 PPT、文献 PDF、录音、秘钥、凭据、私人材料或完整项目目录推送到这里。

本地项目目录中的文件和工作稿仍由用户保管。重要修改在推送前检查 `git status` 与 `git diff --cached`，禁止强制推送、清理删除、重置或覆盖用户未提交的改动。

> 初始化说明：具体允许跟踪的共同文件由仓库 `.gitignore` 白名单控制。新增共享资料前先确认隐私与同步范围。
