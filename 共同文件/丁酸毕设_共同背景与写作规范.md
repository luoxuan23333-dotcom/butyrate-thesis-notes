# 丁酸论文｜当前有效背景与写作规范

> 2026-10-28 更新。规则与事实分开管理；曾经试行但被新导师意见或用户决定取代的写法，不再当作有效要求。

## 一、证据来源与判定

| 标记 | 含义与边界 |
| --- | --- |
| `【原始记录核实】` | 样本、条件、数值可定位到实验原始证据；要写清核查范围 |
| `【导师批注】` | 可定位到正式 Word 批注的直接要求 |
| `【导师正文指令】` | Word 正文中明确插入的写作指令 |
| `【谈话明确】` | 转写语义清楚且与其他证据相互印证的要求 |
| `【作者确认】` | 用户明确确认的写作/工作决定；不能自动推定导师认可 |
| `【执行建议】` | AI 或整理档案提出的可选做法，不代表导师原话 |
| `【待核】` | 来源、数值、版本、统计或文献有疑问，不能填成定论 |

**事实核验优先级**：实验原始记录和可定位证据 > 现稿的数字陈述 > 语音转写或 AI 推测。**导师要求的优先级**：正式批注/正文指令 > 有清晰上下文的谈话 > AI 执行建议。两条优先级适用不同问题，不可混用。

## 二、新近导师要求（2026-10-27 档案摘要，待 S1 逐项定位）

1. 引言的研究进展应先概括主题，再归纳3—5类**真实**代谢工程策略并配代表例证，末尾提出可由文献支持、自然引向本研究的问题。不能按作者列表机械堆文献，也不能无查新证据声称“首次”。
2. 工程菌结果参照导师对 But-1 的示范：改造目的、具体组合操作、与恰当亲本比较的数据、从结果支持的结论。But-1 至 But-6 的亲本与组合构型必须逐级清楚。
3. 三轮诱变分阶段说明 ARTP→UV→ARTP 的各自亲本、候选、入选及独立验证；四种培养基组分为四段单因素比较。5 L 发酵单独解释过程曲线和终点指标。
4. 正式批注要求原图1与原图2合并为一张 A/B 图；子图编号、字体、间距、轴、图例、双语题注以及统计口径统一。
5. 讨论以本研究结果为主语，和文献按宿主、构型、底物、发酵方式、pH、周期等条件进行可比性分析。研究局限不能写成已证实的机制或优势。

## 三、仍有效的已确认写作原则

- 先真实阅读相应研究原文，再引用其准确研究对象、实验条件和结论；不能只依据二手摘要拼文献。
- 结果正文围绕问题与可核实证据推进，保留逐级构建的目的、主要指标及必要副产物分析；不强制堆满所有均值±SD。
- **允许有根据、明确标为解释/假说的机制讨论**；不能把未测的酶活、代谢流、遗传稳定性等说成实验证实的事实。2026-10-16 的用户纠正仍适用。
- 5 L 实验是用前面筛选配方开展的验证链条（用户 2026-10-15 确认），但不同培养条件下的产量差不能拆分成“配方单独作用”或“放大单独作用”。
- 术语、菌株标识、图号、重复数和分母必须与相应原始记录一致。不要把初筛单次记录误称生物学重复，也不要把筛选正向比例当作遗传突变率。
- 优先最小充分修改：按新导师意见调整实质问题；对仍有效的旧稿不因语言有其他写法就推倒重来。

## 四、修改权限与保密

- 默认只审阅、提出方案、形成独立候选稿。未经作者明确授权，不覆盖导师 Word、当前主稿、Excel、PPT、原始图或实验记录。
- 本 GitHub 仓库可在作者授权下**直接覆盖或删除过期知识库文件**；关键是对照新证据确认其不适用，并在 Git 提交中记录改动，避免把未核实的新意见写成定论。
- 未经单独授权，不上传原始 Word、录音、谈话全文、未经脱敏的私人资料、实验原始数据或第三方文献全文。
- 仅因仓库摘要更新，不代表稿件已经修改、导师已认可或满足投稿条件。
