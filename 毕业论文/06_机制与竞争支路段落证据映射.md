### 1.2.1 对应新图：图1-1 绘制规格候选

三条路线均从**butyryl-CoA**出发，终点butyrate。图中至少需要：
1. **PTB–BUK**：butyryl-CoA + Pi → butyryl-phosphate + CoA-SH；butyryl-phosphate + ADP → butyrate + ATP。
2. **CoAT**：butyryl-CoA + acetate ⇌ butyrate + acetyl-CoA；虚线附注**PTA/AK乙酸再生**，阐明ATP收益**来自耦联步骤**，防止把ATP直接画在CoAT箭头上。
3. **TesB**：butyryl-CoA + H2O → butyrate + CoA-SH；标注“末端水解步骤不直接产生ATP”。
4. 图注以**C. acetobutylicum和C. tyrobutyricum的具体证据**举例，标出“代表性路线，不意味着所有天然梭菌的路径完全相同”；TesB路线引用工程E. coli证据。
5. 不复刻小论文已有的完整“中心代谢—竞争支路”图，**新图只比较三类丁酸末端反应**。
6. 科学性特别审查：Lee16中的*cat1*失活尝试未成功获得无争议的功能敲除；应写“联合基因组、蛋白/转录和体外酶活支持CoAT路径，cat1是候选基因”，不写“遗传敲除充分证明其必需”。

**新增对照机制（可一句说明，无须新增图）**：Jaw16使用FASII中的**butyryl-ACP**释放丁酸，它**不同于**本课题CoA连接的AtoB–Hbd–Crt–Ter–TesB路线。Gul24的逆向β-氧化则仍属**CoA连接**的合成路线，虽然使用了具有FASII功能背景的FabI，也不能与butyryl-ACP路线混同。[Jaw16, Gul24]

### 1.3.2 与本课题的证据边界

- 既有小论文已记录But-0至But-6的丁酸与主要有机酸浓度、OD600；上述文献只能帮助解释策略的研究背景，**本文尚无本课题的直接13C通量、酶活和氧化还原测定**。
- But-6为多位点和多异源基因整合的**组合基因型**；看到丁酸增产时不得把效果归因于某一个缺失或插入，除非同构的独立对照支持。
- Jang14的buk/bukII方案说明某些末端反应的选择性优化与副产物调控存在耦联，不应为了分类强行把该文只放“某个基因敲除”。
- 本章无需展开本研究But-1至But-6各轮的具体产量数据，**留给第3章结果与讨论**。本节主要讨论前人研究。
