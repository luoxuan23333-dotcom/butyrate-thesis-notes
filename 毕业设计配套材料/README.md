## 工作范围与分工

本目录服务于四项材料：
1. 毕业设计任务书；
2. 开题报告书；
3. 本科毕业设计中期检查表；
4. 指定丁酸综述的外文文献翻译。

工作模式：ChatGPT 查核事实与研究素材、组织内容并撰写初稿 → Gemini 只做学术表达润色 → ChatGPT 对照原稿再次审核科学事实、逻辑和格式 → 作者验收。不同阶段文件需分别以当时已完成的工作为依据；正式时间节点、院校或项目编号不得套用参考范文。

## 各文件写作边界

开题报告应沿用范文指定栏目，基于当时合理的研究方案组织背景、现状、目的、技术路线和预期目标；任务书需简洁且与开题报告任务一致。中期检查重点是指定时间点完成事项、遇到的实际问题和后续措施；未获得阶段记录前不要编写虚构进度。文献翻译保留原文段落、图表、数值、引文和科学含义。 

本目录后续可新增初稿、Gemini 修改建议、审校台账，但不得覆盖论文英文投稿主稿 `英文投稿/论文英文全文.md`。
