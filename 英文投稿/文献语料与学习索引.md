### A. 中文原稿逐句论证映射（作为后续逐句翻译验收基准）

标记：G背景与意义，R研究现状，E已有研究例证，L局限或反例，J概括判断，Q研究必要性，A本研究行动与范围，O结果，C贡献。**标签是当前句的语言功能而非重写或新增论点许可。**

| 句ID | 中文原句首部或特征 | 功能 / 英译必须保留的信息 |
|---|---|---|
| P1.S01 | 丁酸是一种重要的四碳短链脂肪酸…关键原料[1–3] | G：四碳短链脂肪酸、食品/医药/饲料/化工应用及丁酸酯合成用途，引用[1–3] |
| P1.S02 | 目前，丁酸主要通过化学合成法… | G：化学合成与微生物发酵两种路径，**不要自行改成两种方式各占市场多少** |
| P1.S03 | 随着绿色制造理念的推进…[1–2] | G→R：可再生碳源、绿色制造推动关注度，与化学法对比而非已证实成本优势 |
| P1.S04 | 目前用于丁酸发酵的微生物主要包括… | R：天然产酸菌（典型C. tyrobutyricum）与工程菌株两类来源 |
| P1.S05 | 天然产酸菌虽然…乙酸、乳酸…[1,4] | L：产酸潜力 vs 有机酸副产，影响目标选择性、碳源利用及下游纯化成本；天然菌乳酸生成程度需核，不可自动泛化 |
| P1.S06 | 因此，如何有效减少副产物积累… | Q：凝练成丁酸**滴度(titer)、底物得率(yield)、体积生产强度(volumetric productivity)**三指标提高 |
| P2.S01 | 为提升微生物合成丁酸的效率… | R：概述**前体供应、途径、竞争支路、转运和发酵过程**五类现有策略；这是后面引用的总起句 |

| P2.S03 | 在丁酸合成途径优化方面…4.3/7.2…28.4 [7,8] | E：合成支架异源途径与Ter/PTB-BUK等末端催化策略；必须保留batch/fed-batch/mineral-salt不同工况 |

| P2.S07 | 综上所述，尽管…深度改造…多位点编辑负担[7,9] | J+L：综合局限**外源途径需要宿主竞争支路协同、单一路径敲除不足、多位点改造影响生长和全局代谢**。注意[9]实际主要是单个pta失活，未直接证明广义“多位点编辑负担”，属引用范围待核 |

| P3.S01 | 本研究以巨大芽孢杆菌为出发菌株… | A：宿主、逐级竞争基因缺失与异源基因整合、系统评估丁酸/有机酸副产/生长 |
| P3.S02 | 在此基础上…But-6…ARTP–UV–ARTP… | A：选定But-6作亲本、三轮连续诱变、4组分**顺序单因素**（yeast extract/peptone/corn steep liquor/molasses） |
| P3.S03 | 最终…5L…48h…58.63/0.59/1.22 | O：5 L fed-batch 48h、titer/yield/average volumetric productivity，**0.59g/g原始分母仍待Q-01物料衡算**，先保持源稿数字 |
| P3.S04 | 本研究为利用巨大芽孢杆菌… | C：贡献落在**菌株资源**与**系统工程改造策略**，不是自行升格成工业应用已验证 |

**段落结构锁定为P1六句→P2八句（多处含分号）→P3四句；英语可按自然语法拆合句内成分，但**不得改变中文自然段边界、现有例证的呈现次序、引文编号、研究必要性的落点，也不得擅自压缩第二段“研究综述/局限→研究空白”链条。

### D. 现在可形成的英语专业表达候选（**语言规范候选，不是正文替换**）

- 四碳短链脂肪酸：\`a four-carbon short-chain fatty acid\`；丁酸产量（浓度意义）：\`butyrate titer\`；得率：\`butyrate yield\`（需明确底物分母）；体积生产强度：\`volumetric productivity\`。
- 天然产丁酸菌：\`native butyrate-producing microorganisms\` / \`native butyrate producers\`（不泛称所有菌）；副产物形成/碳流分流：\`by-product formation\` / \`diversion of carbon flux toward competing pathways\`。
- “已有研究策略”可用\`Previous efforts have focused on...\`、\`Strategies to improve butyrate production include...\`（列举五种，依中文顺序）；“虽然…仍然…”可用\`Although ... , ... remains...\`，但先保留两分句真实科学对象。
- “对…改造的研究空白”可用\`Despite these advances, ... remains to be addressed\`或\`It remains necessary to determine how ...\`，空白须是**多元策略在此类底盘的结合**，不可升级成未经检索确认的\`for the first time\` / \`never investigated\`。
- “本研究以…为出发菌株”\`In this study, B. megaterium was used as the starting host ...\`；“在此基础上”\`On this basis,\` / \`Subsequently,\`；“系统考察”\`systematically evaluated...\`，后面指标要齐全。
- 写作禁区：不要因英文范文有4/5段，就拆源中文三段；不要把中文第三段**实际已有的58.63/0.59/1.22结果**自行删掉；不要把文献[1–12]从句尾随意重排；不拿摘要级事实冒充全文论证；不擅将“非理性诱变能缓解代谢扰动”升级成已被本研究转录组/基因组验证的机制。

### E. 待单独科学核实（不改原文引言）

- **I-01** P1.S05 “天然产酸菌往往伴随大量乙酸、乳酸”可能超出单一菌种典型发酵的普遍性，需看[1,4]原文支持范围。
- **I-02** P2.S07 “多位点编辑常对细胞生长及代谢平衡造成负担”仅引[9]，后者重点是\`pta\`单基因突变与生长减缓，**不足以代表多位点编辑的一般机制**；可另寻直接研究文献但不得擅换引文。
- **I-03** P2.S08 理性代谢工程/“非理性诱变缓解代谢扰动并全局激发产酸潜能”的机制性表述，无本稿突变位点、组学或稳定性实验可直接验证；不能将研究设计的期望表述成事实。
- **I-04** P3.S03 0.59g/g丁酸得率无已核明的底物消耗分母、补料过程累积质量/体积变化，沿用既有Q-01阻断。
- **I-05** “已有研究局限→本研究必要性”的衔接目前存在且被保留；是否达到目标期刊对原创性陈述的力度是可供作者后续判断的审稿问题，而**不是翻译自动重构的许可证**。
- **I-06** 具体数字均有摘要/原文支持但原中文中“产量”多指终点浓度，不应英译成\`production amount\`或未经给定分母的\`yield\`；文献对照必须保留不同培养模式条件。
