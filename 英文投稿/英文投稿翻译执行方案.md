## 3. S2–S3 英文表达规范的生成办法

先按文献**逐篇**做真实句子功能分析，再横向归纳，不能用“作者发表过英文论文”当作每句话都正确的证明。

建议建立四类规则（每条记录来源与例外）：

1. **术语**：*butyrate* / *butyric acid*；*titer* / *yield* / *average volumetric productivity*；product selectivity vs B/A ratio vs 丁酸占实测有机酸总量的质量分数。先核对指标定义，再决定英文词。
2. **技术方法**：菌株名称、基因与蛋白斜体、敲除+整合、CRISPR-Cas9、供体与同源臂、ARTP/UV轮次、摇瓶、5 L反应器、测定和重复数；不从其他论文复制本研究未使用的参数。
3. **结果写法**：每句明确主体、处理/亲本或对照、时间和条件、数值与单位，再判断是否支持机制解释。不能把“丁酸终浓度升高”无条件写成“carbon flux increased”。
4. **论证写法**：引言用研究缺口而非作者名单罗列；方法以可复现为准；结果陈述与讨论解释区分；讨论对比前人时注明宿主、基质、反应器、时间等不可比条件。

**Rule状态**：`candidate`（文献观察）、`approved`（作者确认且有适用条件）、`rejected`（不适配）。科学事实与语言喜好冲突时，科学证据和原稿真实含义优先。已发表英文文章若有语法、习惯用法或科研表述问题，要记录为**不宜模仿的反例**。

## 4. S4试译与S5逐节翻译的固定SOP

**翻译顺序**：2.1综合试译 → 1.1–1.8材料方法 → 2.1–2.4结果与分析（2.1采用验收稿，不重复无意义翻译）→ 3讨论与结论 → 引言 → 标题/英文摘要/关键词 → 全文终审。

每小节必须执行：

1. **定位**：登记Word文件名+SHA+章节/段落、已有中英文图注、数值与引用。
2. **拆解**：列出原文每句的事实单元（菌株/基因/目的/对照/条件/数据/判断），找出本节所需高风险术语。
3. **术语核实**：从真实英文原始论文找到支持用法的段落，给不同语境的取舍理由；找不到则标待核，不臆造“国际标准”。
4. **学术英文重构**：以英语学术表达重组主语、时态和信息先后，保留科学含义；不机械逐字翻译，也不把“可能”一律删去。
5. **双向科学核查**：译回为中文要点并逐项与源文比对，检查遗漏、额外内容、因果增强、负结果、时态、统计声明。
6. **验收与交接**：输出英文候选+必要的中英对照+术语依据+本节待核清单；只有通过作者选择才把候选规则标已确认。

**2.1试译特殊要求**：优先覆盖But-1到But-6的逐级组合修改、代表性副产物、OD和通路结构。不能把“敲除A并整合B后的效应”拆成“仅敲除A导致”的因果结论。与稿件现有的Figure 1英文图注保持一致，不修改图注。

**单节五项验收**（无遗漏才算通过）：①术语正确与统一；②英文语法和学科惯用句式；③源文科学含义和全部关键数据保持；④图表/引用/实验条件一致；⑤待核处标清且无未经批准的重大主张变化。

## 7. GitHub × Undermind × Codex交接机制

- **Undermind**保存检索、文献/PDF与专业阅读证据（cite key、来源位置），仅把公开的DOI、索引和精选规则摘要写入GitHub；不要未经授权上传本研究未发表原稿或原始数据。
- **GitHub**是项目跨窗口的**规范和状态权威入口**：本执行方案负责过程；《文献语料与学习索引》负责实际阅读覆盖；《英文术语库》负责候选/确认用词；《英文写作与翻译规范》负责已确认表达边界；《翻译版本与审校记录》负责章节状态与问题。不另建重复日报。
- **ChatGPT/Codex**每次开始读取远端main及上述文件；执行前登记处理章节、源稿SHA、具体文献和已确认规则；写完提供待审核候选；对已确认知识库更新提交Git commit SHA。
- **并行规则**：一窗口负责文献/术语，另一窗口负责指定译稿可以并行；不要同时覆盖同一Markdown或同一章节正文。每次提交前重新获取目标文件最新blob SHA；发现冲突先核对两边内容，不做强推。
- **版本状态**：`not-started`、`researching`、`draft`、`review-needed`、`author-approved`。只因作者明确确认而使用 `author-approved`，文献搜索完成不代表语言学习/译文完成。
- **结束时最低交接**：已读最新commit；当前源稿版本；已完成章节/文献及引用定位；新增candidate/approved规则；未解决事实和学术争议；更新文件及提交SHA；下一节任务。源Word和实验数据仍按仓库权限约定管理。
