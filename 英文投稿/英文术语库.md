| 中文概念 | 推荐英文候选 | 核验重点 |
| --- | --- | --- |
| 丁酸（化合物） | butyric acid | 化学实体或一般用途常用；不要与酸根、盐类无条件等同 |
| 丁酸/丁酸根（发酵产物） | butyrate | 文献中常用作发酵产物名称；按介质和作者定义决定 |
| 丁酸浓度/滴度（g/L） | butyrate titer / butyric acid titer | **不是**yield；不能因中文写“产量”就写yield |
| 得率（g/g） | butyrate yield | 分母必须说明：葡萄糖加入量、消耗量、总糖量等仍待核 |
| 平均体积生产强度（g/(L·h)） | average volumetric productivity | 与titer、yield明确区分，核算对应时间窗 |
| 丁酸/乙酸质量浓度比（B/A） | butyrate-to-acetate ratio | 说明是mass ratio还是molar ratio；不等同于任意定义的selectivity |
| 总有机酸中丁酸质量分数 | mass fraction of butyrate among measured organic acids | 要给出所含有机酸与分母口径；不能替代为B/A |
| 菌株出发株、亲本株 | starting strain; parental strain | 当轮亲本与最初出发株要区分 |
| 竞争性代谢支路 | competing metabolic pathways | 不宣称已直接测量carbon flux |
| 基因敲除 | gene deletion / gene knockout | 基因、位点、宿主应准确；不要把组合效应归因单一基因 |
| 染色体定点整合 | site-specific chromosomal integration | 基因来源、整合位点、拷贝数按实际记录 |
| CRISPR-Cas9介导的同源重组 | CRISPR-Cas9-mediated homologous recombination | 需核查具体载体与供体机制 |
| 异源丁酸合成途径 | heterologous butyrate biosynthetic pathway | heterologous 不等于酶活已经实测提高 |
| 常压室温等离子体诱变（ARTP） | atmospheric and room-temperature plasma mutagenesis | 首次全称，后续统一为 ARTP |
| 紫外诱变 | ultraviolet (UV) mutagenesis | 根据具体照射条件写方法 |
| 三轮连续诱变 | sequential ARTP–UV–ARTP mutagenesis | 不直接写成协同或经过遗传稳定性验证 |
| 初筛 / 独立复筛 | primary screening / independent shake-flask validation | 每轮现稿100株候选+1株亲本对照，摇瓶复筛n=3 |
| 正向株比例 | proportion of improved mutants in screening | 现稿称“正突变率”；避免误让读者理解为每碱基mutation rate |
| 单因素递进培养基优化 | sequential single-factor medium optimization | 不是factorial design / response surface methodology |
| 补料分批发酵 | fed-batch fermentation | 与batch fermentation分清；实际2.4为0–24h batch、24–48h feeding |

## 专题性规则

- *Bacillus megaterium* 是当前中文Word及已定稿英文图注中的名称。国际分类别名 *Priestia megaterium* 的后续处理依目标期刊及作者确认；不得只改正文而遗留图注。
- 基因名称与蛋白/酶名称区别排版；*atoB*, *hbd*, *crt*, *ter*, *tesB* 按期刊基因命名规范核对斜体与来源上标，不在Markdown中猜构型。
- 数值性结论以“当前源稿记载”与“原始数据验证”两种不同状态管理；任何修正必须回到原始测量或表格，而非倒推凑百分比。
- 待重点全文审查：yield分母、OD600是否代表生物量、titer与production区别、positive mutant frequency命名、丙氨酸代谢与碳流结论的证据强度。
